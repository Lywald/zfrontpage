# The Morgue

The paper's memory of itself. One line per edition, appended after each is typeset.
The editor reads this file **before choosing the day's thesis and lesson** — see the
charter. Rules of the morgue:

- **Never reuse a Lesson subject.**
- **Revisit a Leader thesis only to advance it** — say what changed, and cite the
  paper's own prior argument ("as this page argued on July 29"). Follow-ups are
  encouraged; amnesia and reruns are forbidden.
- **Do not recycle coinages.** A phrase lands once.
- When unsure whether something has run before, search `editions/` directly.
